## Focused remaining listening/visual observations

1. **Saturation drive** — Use the actual `Drive` parameter, not EQ `GainDb`. Compare Drive 1 versus 5–10 with a sufficiently strong sustained complex signal and resonance, and also compare recorded exports or FFT/harmonic content if distortion is subtle. Drive is amplitude-normalized, so compare timbre rather than loudness. Excessive drive/resonance need not sound pleasant, but output should be finite.
2. **FIR phase** — A short click/impulse or exported waveform view is more diagnostic than a complex drum performance. 127-tap Linear's 63-sample fixed delay is ~1.3 ms at 48 kHz; Minimum/Maximum largely move energy to earlier/later taps while retaining similar magnitude. Try phase-change reproduction from a fixed note start and compare waveforms; do not interpret barely audible differences as failure.
3. **Nested source (case 10) follow-on only** — Flattened-child channel Filter persistence versus private-mixdown isolation is now audibly **passed**. If undertaking extra coverage, add a sibling channel and instrument/note/channel/speaker Filter; check unrelated sibling processing, doubled master filtering, Note Off/Cut and tail truncation. This broader combination is optional additional coverage, not a reason to discard the passed isolation result.
4. **Speaker settings (case 11)** — With stereo/hard-pan use independent channels, then check settings persistence and legacy RC vs reusable Chain differentiation.
5. **Operating-system/overload (case 12)** — Exercise Linux and Windows with an expensive saturated Ladder + FIR combination at low and increased polyphony. High tap counts can exceed realtime deadlines, so an underrun under stress is not itself a DSP correctness failure. A crashed worker, unbounded diagnostics, corrupted audio, or failure to resume a lighter workload is a failure.

The core flattened-versus-private channel-Filter test of case 10 is passed. The current report does not establish hardware certification or performance on the unreported second operating system.
