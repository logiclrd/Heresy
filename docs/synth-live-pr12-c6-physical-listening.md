## Setup and common observation contract

Use a copy of a test song that you may freely edit, on the same physical Linux output device. Start with **48-kHz stereo** if supported and modest amplitude. Use one sounding note (or **two notes with at most three Multi voices each**) rather than the 17-voice load cases. The actual Synth Test piano accepts `Z S X D C` etc.; its displayed **Mode: Latch / Mode: Hold** label is authoritative. Caps Lock changes this mode (locally tracked on some Wayland sessions); **F8 cuts all preview voices**. The piano must have keyboard focus to accept new note keys. Two latched notes should be at least **three semitones apart**, or the later Note On will cut the nearby earlier one by design. Selecting another Synth graph window, closing the editor or the Test control's lifetime may cut its voices; never infer a DSP defect from deliberately changing playback context.

**Commit numeric fields with Enter or focus loss**, while dropdowns and checkboxes commit immediately. Wait at least **0.3 seconds** between human audible changes to let the standard **100-ms smoothstep** finish. Never require manual edits *during* a 100-ms fade; CI handles precise overlap ordering. Record (a) which note continued, (b) intended sonic change, (c) an audible click/pop/dropout or unexpected restart, (d) whether the status shows **`Playback uses older audio`**, and (e) whether an **Audio underruns** counter rose. **A wrong older-audio warning on a fully compatible update is a C6 failure even if sound is correct**. If actual underruns rise, lower load and distinguish performance from a new DSP logic fault. A warning is **expected** when a sounding old voice has deliberately refused a structural or incompatible revision.

For a **definite Note Off/release** test, start a **new note in Hold mode** and physically release the key while Test remains focused. Changing an already-latched voice's Caps Lock mode does **not** retroactively emit Note Off. F8 sends **Cut**, so it is *not* evidence of a natural release tail.
